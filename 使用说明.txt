兼职匹配工作台 · 使用说明
==================================================

这个工具不联网就没有数据：它从招聘网站真实抓岗位，
所以必须先启动本机的「数据桥」，页面才抓得到东西。


【怎么开始】

1. 解压后，双击  启动工作台.bat
   （黑框一闪是正常的，它在后台跑）

2. 等几秒，浏览器自动打开一个页面。
   如果没自动打开，手动在浏览器输入：
   http://127.0.0.1:8765/

3. 页面右上角点「引擎 未配置」，选一个模型通道，
   填上你自己的 API Key，点「测试连接」。
   （不填模型也能抓岗位，但没法打分）

4. 左栏填：会什么技能、哪个时段有空、城市和最低时薪。

5. 点左下角「开始匹配」。


【几个必须知道的】

· 不要双击「兼职匹配工作台.html」这个文件。
  那样打开浏览器会拦住数据，一条都抓不到。
  一定要通过 http://127.0.0.1:8765/ 打开。

· BOSS直聘 要扫码登录一次。
  「04 平台」卡片下面有「扫码登录 BOSS」按钮，
  点了会弹出一个浏览器窗口，用手机 BOSS App 扫窗口里的码。

· 想关掉服务：任务管理器 → 结束 pythonw.exe


【需要装什么】

Python 3.8 以上（安装时勾选 Add Python to PATH）
Chrome 或 Edge 浏览器
其他什么都不用装，不用 pip install。


【出问题了】

先看 docs 文件夹里的「常见问题.md」。
最快的自查：浏览器打开 http://127.0.0.1:8765/ping
能看到一串文字就说明服务活着。
